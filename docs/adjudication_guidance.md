# 人身损害赔偿裁判思路沉淀

本文件记录项目当前内置的裁判审查提示来源和使用方式。内容仅用于办案辅助和风险提示，不构成法律意见。

## 官方公开来源

1. 最高人民法院《关于审理人身损害赔偿案件适用法律若干问题的解释》
   - 来源：https://gongbao.court.gov.cn/Details/3b032047d8cb44a89a514777ce6dad.html
   - 项目沉淀：2022年5月1日起统一使用城镇居民指标；“上一年度”是一审法庭辩论终结时的上一统计年度；并沉淀各赔偿项目的基础口径和证据要点。

2. 最高人民法院《关于审理道路交通事故损害赔偿案件适用法律若干问题的解释（二）》
   - 来源：https://www.court.gov.cn/fabu/xiangqing/499051.html
   - 生效日期：2026年6月30日。
   - 项目沉淀：超龄劳动者有实际误工损失仍可主张；多个被扶养人先逐人计算再相加，年度总额不超过完整的城镇居民人均消费支出额；基金已支付或垫付费用避免重复受偿。

3. 最高人民法院交通事故责任纠纷典型案例
   - 来源：https://www.court.gov.cn/zixun/xiangqing/480081.html
   - 项目沉淀：责任比例、过错程度、鉴定意见中的误工期/营养期/护理期，通常会影响最终支持金额。

4. 最高人民法院公报案例：尹瑞军诉颜礼奎健康权、身体权纠纷案
   - 来源：https://gongbao.court.gov.cn/Details/3e680f3a7ae2bde2aacfc0a168841a.html
   - 项目沉淀：护理人员收入无法证明时，居民服务业平均工资曾被作为参考；这不是全国统一或当然适用的护理费标准。

5. 最高人民法院《关于确定民事侵权精神损害赔偿责任若干问题的解释》
   - 来源：https://gongbao.court.gov.cn/Details/87b471350704bf50ce1f5e0f9a0e21.html
   - 项目沉淀：精神损害抚慰金应按过错、行为情节、损害后果、责任能力和当地生活水平等因素个案确定，不能机械套用全国统一档位。

## 项目实现

- `adjudication_guidance.py`
  - `review_compensation_claims(amounts, input_data)`：生成每个赔偿项目的法院审查重点、必要证据、缺失证据、风险等级和公开来源。
  - `apply_liability_ratio(amounts, liability_ratio)`：保留原始损失金额，同时按责任比例生成给付金额。

- `compensation_calculator.py`
  - `calculate_total(input_data)`：保留原始金额计算。
  - `calculate_with_review(input_data)`：返回`损失金额`、`责任比例后金额`、`裁判审查提示`。

## 重点提示

- “居民服务、修理和其他服务业年平均工资”不是当然的护理费标准，只是缺少更直接护工劳务报酬证据时的参考口径之一。
- 被扶养人生活费有多人年度总额上限。上限是完整的年度城镇居民人均消费支出额，不能再次乘伤残系数。
- 精神损害抚慰金默认不自动计入；粗略估值和显式输入金额均需律师按当地尺度复核。
- 交通费、住宿费、营养费等项目常见裁判思路是“必要性 + 合理性 + 票据/医嘱/鉴定意见印证”。
- 历史数据采集结果中如果出现`部分提取`，应优先查看`字段溯源`工作表和缺失项，再决定是否人工补充来源。
