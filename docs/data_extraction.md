# 统计数据抽取与复核

采集器将可唯一确认的数值与待核实候选分开保存。`validation_status=verified` 仅表示地区、年度、口径和单位的抽取检查通过，所有导入的标准仍为 `pending`，须由律师或管理员批准后才能用于正式计算。

## 使用

只采集一个省级地区的城镇居民收入、消费支出：

```powershell
.\.venv\Scripts\python.exe data_collector.py --source nbs --region "北京市" --start-year 2024 --end-year 2024 --no-resume
```

同时查询统计局结构化数据和地方公报：

```powershell
.\.venv\Scripts\python.exe data_collector.py --source auto --region "江苏省" --start-year 2024 --end-year 2025
```

`--source bulletin` 只运行地方公报采集。`--output` 指定工作簿，`--status-file` 指定进度 JSON；`--archive-dir` 或环境变量 `STATISTICAL_ARCHIVE_DIR` 指定原文档案目录。网络查询的缓存仅在本次运行内复用；对已完成记录重新检查官网更正时使用 `--no-resume`。新抽取版本或采集模式会重新处理旧进度，避免旧版关键词结果被当成新版已核验数据。

导出内容包括：

- `统计数据`：可以唯一确认的数值；有歧义或冲突时留空。
- `字段溯源`：来源、原值/单位、换算、口径、原文位置、哈希和复核原因。
- `候选复核`：包括未采用值及其地区、年度和未通过检查的原因。
- 同名主 CSV、`_sources.csv`、`_candidates.csv`，以及指定的采集进度 JSON。

JSON 仅包含候选而没有确定数值的字段不会创建统计标准，也不会任取一个候选导入。若该字段已有未批准标准，新冲突会将旧候选标记为失效并禁止批准，避免沿用旧证据；之后唯一确认的新值可重新导入为待审核。此类内容先在“候选复核”工作表中核对，并修正数据源或提供口径明确的公报后重采。

```powershell
personal-injury-import-collector --file data_collection_status.json
```

在 `/workspace` 登录后，使用“统计标准复核”查询对应地区和年度。展开每条标准可以查看原文片段、表头、脚注（有可定位内容时）、单位换算、候选及告警，也可打开官方来源或下载归档原件。只有律师或管理员能批准；地区和年度明确错配时填写说明也不能绕过。

## 已支持的口径与格式

| 项目 | 范围 |
| --- | --- |
| 国家统计局结构化接口 | 31 个省级地区的分省年度城镇居民人均可支配收入、消费支出；按目录、指标 ID、地区名称/代码、四位年份加 `YY` 的统计期编码（例如 `2024YY`）和元单位核对 |
| 计划单列市 | 使用各市官方公报，不用所在省的数值替代；`nbs` 模式明确返回不支持提示 |
| 工资公报 | 就业人员/在岗职工、私营/非私营分别识别；制造业等行业子组不会进入全部行业工资 |
| 居民服务业字段 | 为兼容旧导入保留 `service_industry_wage` 名称，新增抽取明确限定“城镇非私营单位就业人员，居民服务、修理和其他服务业，年平均工资”；其他单位性质作为待核实候选 |
| HTML | 保留表格、多级表头、合并行列和原文位置；正文按明确金额及上下文匹配 |
| XLSX | 只读解析、保留合并表头和工作表/单元格位置，不运行公式；无缓存结果的公式不能产生值 |
| 文字 PDF | 通过 pdfplumber 保留表格、页码和坐标；正文与表格分开处理 |
| 扫描件、复杂版面 | 标记需要 OCR 或人工核对；本次未安装 OCR，也不调用外部大模型 |

`.xls`、CSV 与任意动态页面不是本次新增文档解析格式。页面中同官方域名的 PDF/XLSX 附件最多跟进四个、仅跟进一层；接口改版、缺年、单位变化均返回告警，不降级为全国、月度、上一年或零。

## 原文与更新

原始响应按内容 SHA-256 存储为不可覆盖的文件，同一内容复用归档；请求参数与来源元数据单独留存。Web 下载按登记哈希查找并验证完整性，作为附件返回，不执行归档 HTML。Web 与采集器需共享归档目录并一并备份。Compose 默认读取主机 `data/source_archive`。

跨来源数值只要不同就保留冲突，没有“相差很小就视为相同”的自动容差。相同数值只记录旁证，不因此跳过人工批准。原有批准结果不会被再次导入覆盖；本次尚未增加“已批准标准修订版本”的发布入口，因此更正数据不会自动替换已批准标准。原有案件计算快照继续保存当时采用的值。

## 验证范围

离线测试覆盖错年/错列、多级表头、异地和全国引用、工资群体和行业口径、元/万元换算、冲突保留、原文哈希、归档访问、批准权限和导入维度检查。测试夹具 `tests/fixtures/nbs` 保存了官方北京 2024 年收入、消费响应及获取说明，可离线重放。

已对北京 2024 年做过真实结构化查询与归档验证；这不代表完成全国逐省逐年的覆盖率核验。抽取规则会对不能确定的材料留空，实际资料覆盖率需要持续用人工核对后的公报样本评估。
