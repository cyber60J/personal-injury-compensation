# 新手律师助理工作流：交通事故人身损害赔偿

本文面向没有法律背景的新手律师助理，目标是把项目用于基础文档处理、数据核验、初步试算和证据缺口提示。不要把公式结果直接当作最终赔偿意见，所有结论都应交由律师复核。

## 一句话结论

可以使用本项目做交通事故人身损害赔偿案件的基础处理，但只能作为“辅助工具”：

- 可以做：整理材料、提取赔偿项目、核对统计数据来源、初步计算、生成证据缺口和风险提示。
- 不可以做：直接替代律师判断责任主体、事故责任比例、因果关系、伤残等级争议、保险赔付顺序和法院裁量金额。

## 新手助理处理顺序

### 1. 先判断案件能不能进入本项目

适用场景：

- 交通事故导致人身损害。
- 已经有事故认定书、医疗材料或初步赔偿项目。
- 需要整理赔偿清单、初步测算金额、检查证据缺口。

暂不适合直接套用：

- 工伤、雇佣劳务受害、医疗损害、校园伤害等非交通事故案件。
- 责任主体复杂但材料不足，例如挂靠、借用车辆、网约车平台、拼装报废车、未投保交强险。
- 伤残等级、因果关系、参与度、护理依赖存在明显争议。

### 2. 建立案件基础信息表

必须先整理：

- 事故日期、地点。
- 事故认定书编号。
- 责任划分：全责、主责、同责、次责、无责。
- 车辆、驾驶人、车主、保险公司。
- 交强险、商业三者险、医保或其他垫付情况。
- 受害人年龄、户籍/常住地、职业、收入情况。
- 是否死亡、是否伤残、是否存在被扶养人。

无法从项目自动采集，必须人工审核：

- 事故责任认定书。
- 保险单、保险限额和免赔事项。
- 基本医保、工伤保险基金、道路交通事故救助基金已支付或垫付的项目与金额。
- 驾驶人与车主是否一致。
- 是否存在挂靠、借用、雇佣、好意同乘、拼装报废车等特殊事实。

### 3. 整理医疗和鉴定材料

至少收集：

- 门诊病历、住院病案首页、出入院记录。
- 诊断证明、检查报告。
- 医疗费票据、费用清单。
- 司法鉴定意见：伤残等级、误工期、护理期、营养期、护理依赖、后续治疗费。

无法从项目自动采集，必须人工审核：

- 医疗票据真实性。
- 费用是否与本次事故有关。
- 鉴定意见是否完整、是否有异议。
- 是否存在既往伤病、损伤参与度、二次治疗等问题。

### 4. 按赔偿项目录入数据

常见项目和新手检查点：

| 项目 | 助理录入内容 | 必须人工审核 |
| --- | --- | --- |
| 医疗费 | 票据金额合计 | 票据、病历、诊断是否对应 |
| 误工费 | 日收入或行业工资、误工天数 | 收入减少证明、误工期依据 |
| 护理费 | 护理天数、护理标准 | 护理期、护理人数、护工费证据 |
| 交通费 | 票据金额或合理次数 | 就医路线、陪护必要性 |
| 住院伙食补助费 | 住院天数、当地标准 | 出入院记录、当地标准 |
| 营养费 | 营养天数、日标准 | 医嘱或鉴定意见 |
| 残疾赔偿金 | 年龄、伤残等级、统计年度数据 | 定残日、伤残等级、适用地区 |
| 被扶养人生活费 | 被扶养人年龄、人数、扶养义务人 | 亲属关系、无劳动能力/无生活来源、年度上限 |
| 精神损害抚慰金 | 伤残后果、过错情况 | 地区裁判尺度、责任比例 |

### 5. 统计数据怎么用

本项目可以自动尝试采集：

- 城镇居民人均可支配收入。
- 城镇居民人均消费支出。
- 城镇非私营单位年平均工资。
- 城镇私营单位年平均工资。
- 居民服务、修理和其他服务业年平均工资。

这些数据主要用于：

- 残疾赔偿金、死亡赔偿金：通常关联城镇居民人均可支配收入。
- 被扶养人生活费：通常关联城镇居民人均消费支出。
- 无法证明收入时的误工费：可能参考相同或相近行业职工平均工资。
- 护理费：在缺少实际护工费或护理人员收入证据时，居民服务、修理和其他服务业工资可作为参考口径之一。

重要提醒：

- “居民服务、修理和其他服务业年平均工资”不是当然的护理费标准。
- 统计年度通常看一审法庭辩论终结时的上一统计年度，不一定是事故发生上一年。
- 计划单列市、经济特区、受诉法院所在地等口径要由律师确认。

### 6. 自动采集失败时怎么处理

先看导出的两个表：

- `统计数据`：看每行数据状态。
- `字段溯源`：看每个字段的来源链接、标题、发布时间、采集时间、内容SHA256、官方域名校验和提取片段。

状态含义：

- `已提取`：核心字段完整，但仍需人工抽查来源片段。
- `部分提取`：至少一个核心字段缺失，不能直接用于最终计算。
- `需人工复核`：数值范围或同比变化异常，必须人工确认。
- `未找到`或`提取失败`：不能使用该行自动结果。

需要交给人工审核的情形：

- 来源不是统计局官网，或`官方域名校验=False`。
- 提取片段里看不出数据项和数值的对应关系。
- 同一年同一字段出现多个不同数值。
- 数值明显不像金额，例如被抓成增长率、年份、人数、比例。
- 历史年份缺少工资类数据或消费支出数据。
- 统计局网页改版、附件为图片/PDF扫描件、页面无法访问。

### 7. 公式可以怎么套

可以用作初步试算：

```python
from compensation_calculator import CompensationCalculator

calculator = CompensationCalculator()
report = calculator.calculate_with_review({
    "medical_bills": [12000, 8000],
    "daily_salary": 300,
    "loss_of_work_days": 90,
    "nursing_days": 30,
    "hospitalization_days": 15,
    "nutrition_days": 60,
    "disability_level": 10,
    "age": 35,
    "liability_ratio": 0.8,
    "evidence": {
        "医疗费": ["医疗费票据", "病历", "诊断证明"],
        "误工费": ["医疗机构休假证明或司法鉴定意见", "收入证明"],
        "护理费": ["护理期鉴定意见或医嘱"]
    }
})
```

输出结果应这样使用：

- `损失金额`：理论损失合计。
- `责任比例后金额`：按输入责任比例粗算后的金额。
- `裁判审查提示`：告诉助理哪些项目证据不足、哪些口径需要律师确认。

不能直接使用的情形：

- 没有事故责任比例。
- 没有伤残鉴定或三期鉴定。
- 统计数据状态不是`已提取`。
- 关键证据缺失但仍然输入了金额。
- 有保险赔付顺序、交强险限额、商业险免赔等问题尚未处理。

### 8. 新手助理交付给律师的材料

建议每个案件输出一个文件夹：

```text
案件编号/
├── 01_基础事实表.xlsx
├── 02_证据目录.xlsx
├── 03_赔偿项目试算表.xlsx
├── 04_统计数据溯源表.xlsx
├── 05_缺失材料清单.md
└── 06_需律师判断问题.md
```

`需律师判断问题.md`至少列出：

- 责任比例是否可直接使用事故认定书。
- 是否需要追加车主、保险公司、挂靠公司等主体。
- 是否需要申请伤残、三期、护理依赖、后续治疗费鉴定。
- 护理费、误工费是否有足够证据。
- 统计数据是否已人工核对。
- 是否存在诉讼时效、重复赔偿、医保扣减、垫付款抵扣等问题。

## 最低复核标准

在交给律师前，新手助理至少完成：

- 每个赔偿项目都有对应证据或明确写明缺失。
- 每个统计数据都有官方来源链接和提取片段。
- 所有`部分提取`、`需人工复核`、`未找到`、`提取失败`均已列入人工审核清单。
- 公式试算表和证据目录能互相对应。
- 没有把“可选历史口径”误当作核心必需数据。

## 结论

本项目适合做交通事故人身损害赔偿的基础文档处理和初步试算。新手助理可以按本文流程完成材料整理、证据缺口提示和数据溯源，但不能仅凭公式直接确定最终赔偿金额。凡是数据无法采集、来源不明、证据不足或裁判口径存在争议的部分，都应进入人工审核。
